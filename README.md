## 🚀 What I'm Building

I'm the **Founder & CEO / Tech Lead at TAPPO** — a Saudi FoodTech product built for cafés and restaurants.

TAPPO is designed around one connected journey:

<div align="center">

**Guest → Table → Menu → Order → Team → Operations → Insights**

</div>

The idea is simple:

> **Make ordering easier for customers and operations easier for hospitality teams.**

### 🍽️ What TAPPO brings together
