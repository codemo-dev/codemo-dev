## 🚀 What I'm Building

I'm the **Founder & CEO / Tech Lead at TAPPO**, a Saudi FoodTech platform built for cafés and restaurants.

TAPPO connects:

**Guest → Table → Menu → Order → Team → Operations → Insights**

The goal is simple:

> **Make ordering easier for customers and operations easier for hospitality teams.**

### TAPPO currently focuses on

- 📱 QR-based digital menus for every table
- 🛒 Simple table ordering
- ⚡ Real-time order operations
- 🧑‍💼 Manager & cashier dashboards
- 🛎️ Waiter / service requests
- ⭐ Customer feedback
- 📊 Operational insights
- 🏪 Multi-tenant cafe management

[**Explore TAPPO →**](https://tappo-mvp.vercel.app/)
